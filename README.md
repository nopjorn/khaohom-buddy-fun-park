# สวนสนุกคู่หู 🎡

เกม 2 คนสำหรับเด็ก 5 ขวบกับผู้ปกครอง เล่น**พร้อมกัน**บนจอเดียว จอแบ่งครึ่ง ฝั่งหนึ่งของลูก อีกฝั่งของผู้ปกครอง
ออกแบบสำหรับ iPad และเล่นบนคอมพิวเตอร์ด้วยคีย์บอร์ดได้ด้วย

**เล่นได้ที่** https://nopjorn.github.io/khaohom-buddy-fun-park/

## สิ่งที่ได้ฝึก

| โซน | กิจกรรม | ระดับของลูก จากง่ายไปยาก (ปรับเองตามผลการตอบ) |
|---|---|---|
| 🔢 ตัวเลข | นับภาพแล้วเลือกตัวเลข | 1. นับ 1-5<br>2. นับถึง 10<br>3. กลุ่มไหนมากหรือน้อยที่สุด<br>4. บวกด้วยภาพ |
| 🐔 ก ไก่ | จับคู่ตัวอักษรไทยกับภาพ (29 ตัว) | 1. ตัวที่พบบ่อย เลือกภาพ<br>2. ทุกตัว เลือกภาพ<br>3. เห็นภาพ เลือกตัวอักษร<br>4. เลือกภาพโดยไม่บอกคำ |
| 🔤 ABC | คำศัพท์และตัวอักษรอังกฤษ | 1. ฟังคำ เลือกภาพ<br>2. เห็นตัวอักษร เลือกภาพที่ขึ้นต้นด้วยตัวนั้น<br>3. ตัวพิมพ์ใหญ่ เลือกตัวพิมพ์เล็ก<br>4. เห็นภาพ เลือกตัวอักษรขึ้นต้น |

| 🧠 ฝึกสมอง | อะไรมาต่อ (แบบรูป) | 1. AB<br>2. AAB, ABB<br>3. ABC<br>4. AABB, ABAC, ABCC |
| 🎲 สุ่มรวม | ทุกกิจกรรมสลับกัน | ตามระดับของแต่ละกิจกรรม |

ฝั่งลูกมีเสียงอ่านโจทย์ให้ จึงเล่นได้แม้ยังอ่านไม่ออก ฝั่งผู้ปกครองได้โจทย์อีกชุดที่ยากกว่า เช่น บวกลบไม่เกิน 20 ตัวอักษรที่หน้าตาคล้ายกัน และเลือกคำที่สะกดถูก

## วิธีเล่น

1. กด **เล่นเลย** แล้วเลือกโซน: ตัวเลข, ก ไก่, ABC, ฝึกสมอง หรือสุ่มรวม
2. เลือกโหมด
   - 🤝 **ช่วยกัน**: ตอบถูกฝั่งไหนก็เติมพลังจรวด ถ้าสองฝั่งตอบถูกภายใน 3 วินาทีได้โบนัสไฮไฟว์ ผู้ปกครองกด "ช่วยลูก" เพื่อให้คำใบ้ได้
   - 🏁 **แข่งกัน**: ใครได้ 8 ดาวก่อนชนะ ผู้ปกครองได้โจทย์ยากกว่าและขึ้นช้ากว่า
3. จบเกมได้สติกเกอร์สะสมหนึ่งดวง

ระหว่างเล่นกดปุ่ม ↔️ ที่แถบกลางเพื่อสลับฝั่งซ้ายขวา (หรือ ↕️ สลับบนล่างในท่านั่งตรงข้าม) เกมจะจำฝั่งไว้ใช้ครั้งต่อไป

ความยากฝั่งลูกปรับเอง ตอบถูก 3 ข้อติดเลื่อนขึ้น ตอบผิด 2 ครั้งติดเลื่อนลง ตอบผิดไม่เสียคะแนน

หน้าตั้งค่าเข้าได้โดย**กดค้าง**ปุ่ม "ผู้ปกครอง" ที่หน้าแรก 2 วินาที ตั้งได้ดังนี้

- ชื่อลูกและชื่อผู้ปกครอง
- แต้มต่อของผู้ปกครอง (ยิ่งมาก โจทย์ฝั่งผู้ปกครองยิ่งขึ้นช้า)
- ท่านั่ง: นั่งข้างกัน หรือนั่งตรงข้ามซึ่งหมุนแผงด้านบนกลับหัว
- เปิดปิดเสียงเอฟเฟกต์และเสียงอ่านโจทย์ พร้อมปุ่มทดสอบเสียง
- ล้างระดับและสติกเกอร์

ระดับ สติกเกอร์ และการตั้งค่า เก็บอยู่ในเบราว์เซอร์ของเครื่องนั้นเท่านั้น แต่ละเครื่องจึงมีข้อมูลของตัวเอง

บน iPad แนะนำให้เปิดใน Safari แล้วเลือก แชร์ → **เพิ่มไปยังหน้าจอโฮม** จะได้เล่นแบบเต็มจอและเล่นออฟไลน์ได้

### เล่นบนคอมพิวเตอร์ด้วยคีย์บอร์ด

เครื่องที่ไม่มีจอสัมผัสจะมีป้ายชื่อปุ่มขึ้นที่มุมของแต่ละช่อง สองคนกดพร้อมกันได้บนคีย์บอร์ดเดียว

| | แผงฝั่งซ้าย (ปกติคือลูก) | แผงฝั่งขวา (ปกติคือผู้ปกครอง) |
|---|---|---|
| ตัวเลือก 3 ข้อ | `A` `S` `D` | `J` `K` `L` |
| ตัวเลือก 2 แถว | `Q` `W` `E` / `A` `S` `D` | `U` `I` `O` / `J` `K` `L` |
| เกมจับคู่ภาพ | `Q W E R` / `A S D F` / `Z X C V` | `7 8 9 0` / `U I O P` / `J K L ;` / `M , . /` |

ตำแหน่งปุ่มบนคีย์บอร์ดตรงกับตำแหน่งช่องบนจอ ปุ่มอื่น: `Space` ฟังโจทย์ซ้ำ, `Enter` ช่วยลูก (โหมดช่วยกัน), `Esc` พักเกม
ใช้ได้ทั้งตอนคีย์บอร์ดเป็นภาษาไทยและอังกฤษ และถ้ากดสลับฝั่ง ปุ่มจะย้ายตามตำแหน่งแผง คนที่อยู่ซ้ายใช้ครึ่งซ้ายของคีย์บอร์ดเสมอ

เสียงอ่านโจทย์ภาษาไทยบน Windows ให้เปิดด้วย Microsoft Edge และต่ออินเทอร์เน็ต เพราะเสียงไทยของ Edge เป็นเสียงออนไลน์ ถ้าเบราว์เซอร์ไม่มีเสียงไทย เกมจะข้ามเสียงไปและแสดงโจทย์เป็นข้อความอย่างเดียว ตรวจได้จากปุ่มทดสอบเสียงในหน้าตั้งค่า

## ลองเล่นในเครื่อง

บน Windows ดับเบิลคลิก `dev.cmd` เกมจะเปิดในเบราว์เซอร์ที่ `http://localhost:5173` และรีเฟรชเองเมื่อแก้โค้ด ปิดหน้าต่างดำเพื่อหยุด
ถ้า Node หลักของเครื่องเก่ากว่ารุ่น 20 สคริปต์จะใช้รุ่นที่ติดตั้งผ่าน nvm ให้เองเฉพาะหน้าต่างนั้น

### รันบนโน้ตบุ๊ก

**แบบที่ 1 รันบนโน้ตบุ๊กเอง** (เล่นได้ทุกที่ ไม่ต้องต่อเน็ตหลังติดตั้งเสร็จ)

1. ติดตั้ง Node รุ่น 20 ขึ้นไปจาก [nodejs.org](https://nodejs.org) (เลือกรุ่น LTS) แล้วเช็กด้วย `node -v`
2. ก๊อปโฟลเดอร์โปรเจกต์ไปไว้ที่โน้ตบุ๊ก ไม่ต้องเอา `node_modules` กับ `dist` ไปด้วย
3. สั่งรัน
   - Windows: ดับเบิลคลิก `dev.cmd` ครั้งแรกจะติดตั้งแพ็กเกจให้เองก่อน (ต้องต่อเน็ต)
   - macOS / Linux: เปิด Terminal ในโฟลเดอร์โปรเจกต์แล้วสั่ง

     ```bash
     npm install              # ครั้งแรกครั้งเดียว
     npm run dev -- --open
     ```

เกมจะเปิดที่ `http://localhost:5173` หยุดด้วยการปิดหน้าต่างหรือกด `Ctrl+C`

**แบบที่ 2 เปิดจากเครื่องหลัก** (โน้ตบุ๊กไม่ต้องติดตั้งอะไร แต่ต้องอยู่ Wi-Fi เดียวกัน)

1. ที่เครื่องหลัก เปิด Terminal ในโฟลเดอร์โปรเจกต์แล้วสั่ง `dev.cmd --host` (ใน PowerShell หรือ Git Bash ใช้ `./dev.cmd --host`)
2. ดูที่อยู่ในบรรทัด `Network:` ที่ขึ้นในหน้าต่างนั้น เช่น `http://192.168.1.23:5173`
3. เปิดที่อยู่นั้นในเบราว์เซอร์ของโน้ตบุ๊ก

ถ้า Windows ถามเรื่อง Firewall ตอนรันครั้งแรก ให้กดอนุญาตสำหรับเครือข่ายส่วนตัว ไม่อย่างนั้นโน้ตบุ๊กจะเข้าไม่ได้

โน้ตบุ๊กที่ไม่มีจอสัมผัสเล่นด้วยคีย์บอร์ดได้ตามตารางในหัวข้อ "เล่นบนคอมพิวเตอร์ด้วยคีย์บอร์ด" ด้านบน

## พัฒนาต่อ

ต้องใช้ Node 20 ขึ้นไป

```bash
npm install
npm run dev        # เปิดที่ http://localhost:5173
npm test           # เทสต์ตรรกะของเกม
npm run typecheck
npm run build      # ผลลัพธ์อยู่ใน dist/
```

ลองบน iPad ก่อนเผยแพร่: `npm run dev -- --host` (หรือ `dev.cmd --host`) แล้วเปิด `http://<IP ของคอม>:5173` ผ่าน Wi-Fi เดียวกัน

สร้างด้วย Vite และ TypeScript ไม่ใช้ framework ภาพทั้งหมดเป็น emoji และเสียงสร้างในเบราว์เซอร์ จึงไม่มีไฟล์ภาพหรือเสียงในโปรเจกต์

โครงสร้างหลัก

- `src/activities/` ตัวสร้างโจทย์ของแต่ละกิจกรรม เป็นฟังก์ชันล้วนที่ทดสอบได้ และส่วนแสดงผลของโจทย์
- `src/engine/` กติกาสองโหมด การปรับระดับ สติกเกอร์ และแผงผู้เล่น
- `src/screens/` หน้าจอต่าง ๆ
- `src/core/` ส่วนพื้นฐาน: การแตะ, ผังปุ่มคีย์บอร์ด, เสียงพูด, เสียงเอฟเฟกต์, การบันทึกข้อมูล, ตัวสุ่ม
- `src/data/` ตัวอักษร คำศัพท์ และภาพที่ใช้ในโจทย์
- `tests/` เทสต์ตรรกะของเกม (ตัวสร้างโจทย์ กติกา การปรับระดับ ผังปุ่ม)

แนวทางสำหรับการแก้โค้ดต่อดูได้ใน [CLAUDE.md](CLAUDE.md)
