# สวนสนุกคู่หู 🎡

เกม 2 คนสำหรับเด็ก 5 ขวบกับผู้ปกครอง เล่น**พร้อมกัน**บน iPad เครื่องเดียว จอแบ่งครึ่ง ซ้ายของลูก ขวาของผู้ปกครอง

## วิธีเล่น

1. กด **เล่นเลย** แล้วเลือกโซน: ตัวเลข, ก ไก่, ABC, ฝึกสมอง หรือสุ่มรวม
2. เลือกโหมด
   - 🤝 **ช่วยกัน**: ตอบถูกฝั่งไหนก็เติมพลังจรวด ถ้าสองฝั่งตอบถูกภายใน 3 วินาทีได้โบนัสไฮไฟว์ ผู้ปกครองกด "ช่วยลูก" เพื่อให้คำใบ้ได้
   - 🏁 **แข่งกัน**: ใครได้ 8 ดาวก่อนชนะ ผู้ปกครองได้โจทย์ยากกว่าและขึ้นช้ากว่า
3. จบเกมได้สติกเกอร์สะสมหนึ่งดวง

ความยากฝั่งลูกปรับเอง ตอบถูก 3 ข้อติดเลื่อนขึ้น ตอบผิด 2 ครั้งติดเลื่อนลง
หน้าตั้งค่า (ชื่อ, แต้มต่อ, เสียง, ท่านั่ง) เข้าได้โดย**กดค้าง**ปุ่ม "ผู้ปกครอง" ที่หน้าแรก 2 วินาที

บน iPad แนะนำให้เปิดใน Safari แล้วเลือก แชร์ → **เพิ่มไปยังหน้าจอโฮม** จะได้เล่นแบบเต็มจอและเล่นออฟไลน์ได้

## พัฒนาต่อ

ต้องใช้ Node 20 ขึ้นไป

```bash
npm install
npm run dev        # เปิดที่ http://localhost:5173
npm test           # เทสต์ตรรกะของเกม
npm run typecheck
npm run build      # ผลลัพธ์อยู่ใน dist/
```

ลองบน iPad ก่อนเผยแพร่: `npm run dev -- --host` แล้วเปิด `http://<IP ของคอม>:5173` ผ่าน Wi-Fi เดียวกัน

โครงสร้างหลัก

- `src/activities/` ตัวสร้างโจทย์ของแต่ละกิจกรรม เป็นฟังก์ชันล้วนที่ทดสอบได้
- `src/engine/` กติกาสองโหมด การปรับระดับ และแผงผู้เล่น
- `src/screens/` หน้าจอต่าง ๆ
- `src/data/` ตัวอักษร คำศัพท์ และภาพที่ใช้ในโจทย์

## เผยแพร่บน GitHub Pages

ทุกครั้งที่ push เข้า `main` GitHub Actions จะตรวจโค้ด, build และ deploy ให้เอง (ดู `.github/workflows/deploy.yml`)
ตั้งค่าครั้งแรกครั้งเดียวที่ Settings → Pages → Source เลือก **GitHub Actions**
